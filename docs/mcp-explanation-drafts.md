# 외부 에이전트 대본 받기

앱의 **에이전트** 탭에서 기본 지시 또는 여러 사용자 지시를 선택합니다. **새 지시…**에서 이름과 본문을 로컬에 저장합니다. 저장한 지시는 이름으로 찾을 수 있고, 본문 전체를 확인하거나 복사할 수 있습니다. 선택·저장·이름 변경만으로는 외부 공유나 모델 호출이 일어나지 않습니다. 기존 **전체 해설**, **변경분만**, **음성 대본 정규화**와 설정은 그대로입니다.

## 서명된 로컬 도우미 (선택)

도우미 없이도 대본을 붙여넣고 편집할 수 있습니다. 자동 수신은 **실제로 조회했던 지시의 정확한 버전**을 연결된 도우미가 증명할 때만 가능합니다. 이 증명은 에이전트가 지시를 받았다는 뜻이지, 어떤 모델을 썼거나 그 지시를 따랐다는 증거는 아닙니다.

1. MCP 클라이언트에 한 번만, 신뢰하는 로컬 인증서로 서명된 앱에 포함된 **CodebasicAgentMCP**를 stdio 명령으로 등록합니다. 별도 인자, 환경 변수, PID, 포트 또는 소켓 경로를 입력하지 않습니다. 앱과 도우미는 macOS가 제공하는 연결 상대 정보로 같은 서명과 예외 없는 강화 런타임을 확인합니다. 앱은 함께 빌드한 도우미의 코드 해시도 확인합니다.
2. Codebasic TTS를 열고 MCP 클라이언트를 시작합니다. **에이전트** 탭에 자동 연결 상태가 표시됩니다. 앱이 닫혔다면 도구가 앱을 열라고 안내합니다. 앱을 연 뒤 같은 MCP 세션에서 다시 시도할 수 있습니다. 한 번에 한 MCP 세션만 연결되며, 앱이나 도우미가 재시작되면 이전 승인과 증명은 사라집니다.
3. **에이전트에 연결할 지시 선택**에서 지시를 직접 선택하면 추가 확인 창 없이 그 버전만 공유하고, 그 버전의 대본을 받습니다. 자동으로 강조된 지시, 연결 전 둘러보기, 저장·편집은 공유하지 않습니다. 외부 에이전트가 원격 모델을 쓰면 받은 지시를 모델 서비스에 보낼 수 있습니다.
4. 다른 지시를 선택하거나, 활성 지시를 편집·삭제하거나, **공유 및 수신 중지**를 누르면 이전 지시와 대본 수신 증명이 모두 취소됩니다. 돌아가는 것만으로 이전 증명이 복원되지 않습니다. 이미 받은 대본은 그대로 남습니다.
5. 새 대본은 **받은 대본 미리 보기**에 즉시 표시됩니다. 최신 대본이 위에 추가되고 여러 건을 스크롤해서 볼 수 있습니다. **편집기에 열기…**로 직접 열 때만 편집 내용이 바뀝니다. **그대로 재생**을 누를 때만 현재 음성 엔진을 사용합니다.

```toml
[mcp_servers.codebasic_tts_agent]
command = "/absolute/path/to/Codebasic TTS.app/Contents/Helpers/CodebasicAgentMCP"
```

앱의 **MCP 설정 복사** 메뉴로 현재 번들 경로가 포함된 Codex 설정이나 Claude Code 사용자 범위 등록 명령을 복사할 수 있습니다. 복사만으로 설정 파일을 바꾸거나 명령을 실행하지 않습니다. 다른 stdio MCP 클라이언트에도 같은 절대 경로를 실행 명령으로 지정하면 됩니다. 앱을 옮기거나 이름을 바꾸면 이 명령 경로만 수정하세요. 전역 에이전트 설정은 앱이 변경하지 않습니다.

- `tts_agent_status`: 앱 연결과 두 권한의 상태를 확인합니다. 지시나 대본은 읽지 않습니다.
- `get_tts_instructions`: 인자 없이 호출하면 앱이 승인한 선택을 읽습니다. 정확한 `profile` ID를 지정하는 기존 호출도 지원합니다. 기존 기본 ID는 `explain`, `continue`, `normalize`입니다. 답변의 `revision`과 `body_sha256`은 정확한 버전과 UTF-8 원문을 식별합니다. 수신 증명은 도우미 내부에서만 관리됩니다.
- `submit_explanation_draft`: 읽은 `profile`과 `revision`, `display_text`, 선택적인 `speech_text`, `idempotency_key`를 보냅니다. 재시도는 같은 키와 같은 내용으로 요청하세요. 접수는 편집기 적용이나 재생 완료를 뜻하지 않습니다.
- 호환용 기존 기본 지시 조회와 `speak_text`는 각각 그대로입니다. 증명 없는 이전 `mcp_tts_draft.py`는 자동 수신하지 않으며 붙여넣기를 안내합니다. 각 권한은 별개입니다.
- 선택에 따른 공유와 수신은 최대 10분, 지시·화면 글·음성 대본은 각각 UTF-8 8 KiB, 보관함은 8개까지입니다. 수신 승인당 20개, 분당 6개까지 새로 받습니다. 기존의 한도 초과 원문은 자르지 않으며 공유되지 않습니다.
- 보관함, 수신 증명, 도우미 승인 기록은 앱을 종료하면 사라집니다. 재생 후에는 기존 설정에 따라 음성 캐시·기록에 남을 수 있습니다.
- 앱이 비정상 종료되면 앱 재시작 및 다음 승인 시 이 버전이 만든 것으로 확인되고 더 이상 연결되지 않는 소켓에 한해 자동으로 복구합니다. “기존 소켓의 출처를 확인할 수 없어 그대로 두었습니다”가 보이면, 이전 **Codebasic TTS** 앱을 종료하고 새 앱에서 같은 동작을 다시 시도하세요. 계속 막히면 복사·붙여넣기를 사용하세요. 관리자가 정확한 경로가 종료된 이전 앱의 소켓임을 별도로 확인한 경우에만 그 항목을 다른 곳으로 옮길 수 있습니다. 경로 전체나 출처를 모르는 파일은 삭제하지 마세요.

## 합성 데이터로 확인

`TTS_REQUIRE_STABLE_SIGNING=1 ./build.sh build`는 앱과 도우미의 안정적인 서명과 강화 런타임을 확인합니다. `./build.sh test`는 둘 이상의 프로세스에서 로컬 저장 충돌과 소켓 재시작을 포함한 테스트를 실행합니다. `Tests/Fixtures/run_local_draft_candidate.py`는 작업트리 `build/` 안에서 서명된 실제 stdio 프로토콜로 자동 연결, 앱 재시작, 기본 차단, 신뢰할 수 없는 프로세스 거절, 실제 조회 증명, 재수신, 편집·되돌리기·삭제 및 취소를 검증합니다. 실제 설치 앱, 저장된 사용자 지시, 음성 제공자 및 재생은 사용하지 않습니다.
