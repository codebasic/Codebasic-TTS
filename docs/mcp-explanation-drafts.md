# 외부 에이전트 대본 받기

앱의 **에이전트** 탭에서 기본 지시 또는 여러 사용자 지시를 선택합니다. **새 지시…**에서 이름과 본문을 로컬에 저장합니다. 저장한 지시는 이름으로 찾을 수 있고, 본문 전체를 확인하거나 복사할 수 있습니다. 선택·저장·이름 변경만으로는 외부 공유나 모델 호출이 일어나지 않습니다. 기존 **전체 해설**, **변경분만**, **음성 대본 정규화**와 설정은 그대로입니다.

## 서명된 로컬 도우미 (선택)

도우미 없이도 대본을 붙여넣고 편집할 수 있습니다. 자동 수신은 **실제로 조회했던 지시의 정확한 버전**을 연결된 도우미가 증명할 때만 가능합니다. 이 증명은 에이전트가 지시를 받았다는 뜻이지, 어떤 모델을 썼거나 그 지시를 따랐다는 증거는 아닙니다.

1. 이미 신뢰하는 로컬 인증서로 빌드한 앱의 **CodebasicAgentMCP**를 호스트에 설정합니다. 앱과 도우미는 같은 서명 인증서와 예외 없는 macOS 강화 런타임을 쓰며 앱은 함께 빌드한 도우미의 코드 해시도 확인합니다. [앱 서명 고정](mcp-codex-quick-test.md#실제-연결의-서명-고정)에서 인증서 공개 지문 확인 방법을 참고하세요. 서명되지 않았거나 지문이 다른 연결은 실패합니다. 기존 도우미가 새 앱과 연결되지 않으면 새 앱에 포함된 도우미로 교체하세요.
2. 호스트를 새 세션으로 시작합니다. 지시를 요청하면 승인 전에는 본문 대신 도우미 PID가 표시됩니다. 앱에서 **서명된 도우미 연결…**로 실제 PID와 내가 지은 표시 이름을 입력합니다. 이름은 Mac에서만 표시되며 인증 정보가 아닙니다. 도우미를 다시 연결하거나 재시작하면 이전 승인과 증명이 사라집니다.
3. **정확한 지시 미리 보기**에서 지시 ID와 원문을 확인하고, **이 버전만 조회 허용…**에서 파일·프로필 목록이 아니라 해당 원문만 줘도 되는지 확인합니다. 다른 프로필을 고르더라도 이전 조회 권한은 바뀌지 않습니다. 외부 에이전트가 원격 모델을 쓰는 경우 읽은 내용을 모델 서비스로 보낼 수 있습니다.
4. **대본 받기 허용…**은 별도 승인입니다. 지시를 고치거나 되돌리면 읽기 권한은 복구되지 않습니다. 해당 지시가 삭제되지 않았고 도우미·수신 권한·전달 증명이 유효하면, 편집 전에 받은 버전의 대본도 **이전 버전**으로 받을 수 있습니다. 삭제한 지시는 더 받을 수 없지만 이미 받은 대본은 남습니다.
5. **받은 대본 확인**에서 열기 전까지는 기존 편집기를 바꾸지 않습니다. 화면 글과 음성 대본이 다르면 두 내용을 확인하고, 편집으로 달라졌다면 다시 확인하거나 **화면 글 그대로 읽기**를 선택합니다. **그대로 재생**은 명시적으로 누를 때만 현재 음성 엔진을 사용합니다. SSML, 인코딩된 태그, 에이전트 단계 제어 표기를 음성에 쓰지 않습니다. 화면 글은 보존하고, 필요한 경우 음성 대본에서 말로 풀어 쓰세요.

```toml
[mcp_servers.codebasic_tts_agent]
command = "/absolute/path/to/Codebasic TTS.app/Contents/Helpers/CodebasicAgentMCP"
[mcp_servers.codebasic_tts_agent.env]
CODEBASIC_TTS_SIGNER_SHA1 = "TRUSTED_CERT_SHA1_40_HEX"
```

- `get_tts_instructions`: 앱이 승인한 정확한 `profile` ID를 전달합니다. 기존 기본 ID는 `explain`, `continue`, `normalize`입니다. 답변의 `revision`과 `body_sha256`은 정확한 버전과 UTF-8 원문을 식별합니다. 수신 증명은 도우미 내부에서만 관리됩니다.
- `submit_explanation_draft`: 읽은 `profile`과 `revision`, `display_text`, 선택적인 `speech_text`, `idempotency_key`를 보냅니다. 재시도는 같은 키와 같은 내용으로 요청하세요. 접수는 편집기 적용이나 재생 완료를 뜻하지 않습니다.
- 호환용 기존 기본 지시 조회와 `speak_text`는 각각 그대로입니다. 증명 없는 이전 `mcp_tts_draft.py`는 자동 수신하지 않으며 붙여넣기를 안내합니다. 각 권한은 별개입니다.
- 두 권한은 각각 최대 10분, 지시·화면 글·음성 대본은 각각 UTF-8 8 KiB, 보관함은 8개까지입니다. 수신 승인당 20개, 분당 6개까지 새로 받습니다. 기존의 한도 초과 원문은 자르지 않으며 공유되지 않습니다.
- 보관함, 수신 증명, 도우미 승인 기록은 앱을 종료하면 사라집니다. 재생 후에는 기존 설정에 따라 음성 캐시·기록에 남을 수 있습니다.
- 앱이 비정상 종료되면 다음 승인 시 이 버전이 만든 것으로 확인되고 더 이상 연결되지 않는 소켓에 한해 자동으로 복구합니다. “기존 소켓의 출처를 확인할 수 없어 그대로 두었습니다”가 보이면, 이전 **Codebasic TTS** 앱을 종료하고 새 앱에서 같은 동작을 다시 시도하세요. 계속 막히면 복사·붙여넣기를 사용하세요. 관리자가 정확한 경로가 종료된 이전 앱의 소켓임을 별도로 확인한 경우에만 그 항목을 다른 곳으로 옮길 수 있습니다. 경로 전체나 출처를 모르는 파일은 삭제하지 마세요.

## 합성 데이터로 확인

`TTS_REQUIRE_STABLE_SIGNING=1 ./build.sh build`는 앱과 도우미의 안정적인 서명과 강화 런타임을 확인합니다. `./build.sh test`는 둘 이상의 프로세스에서 로컬 저장 충돌과 소켓 재시작을 포함한 테스트를 실행합니다. `Tests/Fixtures/run_local_draft_candidate.py`는 작업트리 `build/` 안에서 서로 다른 서명·프로세스, 실제 조회 증명, 재수신, 편집·되돌리기·삭제 및 취소를 검증합니다. 실제 설치 앱, 저장된 사용자 지시, 음성 제공자 및 재생은 사용하지 않습니다.
