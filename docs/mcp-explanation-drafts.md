# 외부 에이전트 대본 받기

앱은 에이전트 지시문을 관리하고, 외부 에이전트가 작성한 대본을 사용자가 검토·편집한 뒤 읽습니다.
에이전트는 입력 자료·모델·생성 맥락을 별도로 관리합니다. 앱의 **에이전트** 기본 화면은 해설·비전·발음 정규화 모델을 호출하지 않습니다. 기본 지시 프로필은 코드 해설용이며, 대본 편집과 재생에는 꼭 코드나 해설이 필요하지 않습니다.

## 사용 흐름

1. **에이전트 지시문**에서 코드 해설용 **전체 해설** 또는 **변경분만**을 고릅니다. 기본 지시를 편집하고 공통 규칙까지 포함한 정확한 문구를 복사하거나, 승인한 로컬 도우미에 한해 [읽기 전용 MCP 지시 조회](mcp-instruction-profiles-plan.md)를 허용할 수 있습니다. 조회 허용 상태는 에이전트가 조회하거나 모델을 호출했다는 뜻이 아닙니다.
2. 에이전트가 반환한 화면 글을 직접 붙여넣거나, 별도의 **대본 받기 허용…**으로 자동 수신을 켭니다. 화면용 `as_frame`과 음성용 `애즈 프레임`처럼 두 텍스트를 다르게 받을 수 있습니다. 정확한 발음용 텍스트는 에이전트가 직접 쓰거나 사용자가 편집합니다.
3. 자동 수신 대본은 **받은 대본 확인**에서 선택해 열어야 합니다. 편집 중인 글을 바꾸기 전에 확인합니다. **그대로 재생**을 사용하면 현재 음성 엔진만 작동합니다. 화면 글을 고친 후에는 기존 음성 대본을 다시 확인하거나 **화면 글 그대로 읽기**를 선택해야 합니다. 발음용 문단 분할은 사용할 수 있지만 모델이 대본을 다시 쓰지는 않습니다.
4. 읽기 전에 수정하거나 폐기할 수 있습니다. 해설 지시 조회, 대본 수신, 즉시 재생용 [`speak_text`](mcp-speech.md)는 서로 다른 허용입니다. 하나를 켜도 다른 기능은 켜지지 않습니다.

## 로컬 MCP 설정 (선택)

아래는 이미 신뢰하는 Mac 프로젝트의 예시입니다. [앱 서명 고정](mcp-codex-quick-test.md#실제-연결의-서명-고정)으로 구한 인증서 지문과 해당 체크아웃의 절대 경로를 사용합니다. 앱 인증에 실패하면 대본은 전송되지 않습니다.

```toml
[mcp_servers.codebasic_tts_draft]
command = "/usr/bin/python3"
args = ["-I", "-B", "/absolute/path/to/SelectedTextTTS/scripts/mcp_tts_draft.py"]
[mcp_servers.codebasic_tts_draft.env]
CODEBASIC_TTS_SIGNER_SHA1 = "TRUSTED_CERT_SHA1_40_HEX"
```

`submit_explanation_draft`는 `display_text`, 선택적인 `speech_text`, `idempotency_key`만 받습니다.
글은 UTF-8로 필드당 최대 8,192바이트입니다. 첫 요청의 대본은 허용이 꺼져 있으면 전송되지 않으며, 오류 응답에 나오는 **대본 도우미 PID**만 앱에서 승인합니다. 같은 Mac 계정에서 동일 도우미가 살아 있는 동안 최대 10분 유효합니다.

- `accepted`: 임시 보관함에 들어갔습니다. 편집기 적용·재생을 뜻하지 않습니다.
- `duplicate`: 최근에 같은 키와 내용으로 받은 대본입니다. 새 항목을 넣지 않았습니다.
- `unconfirmed`: 결과를 확인하지 못했습니다. 재시도는 **같은 키와 같은 내용**으로 합니다.
- 임시 보관함은 최대 8개이며 앱 종료 시 사라집니다. 수신을 끄면 이미 받은 대본은 이번 실행의 보관함에 남습니다.

전송은 지정된 앱 서명을 확인한 Mac 계정의 로컬 Unix 소켓만 사용합니다. 명시적 재생을 누르면
선택한 클라우드 음성 엔진으로 음성 대본이 전송되거나, 기존 설정에 따라 재생 기록·캐시에 남을 수 있습니다.

## 격리 회귀 확인

`./build.sh test`는 MCP 프레이밍·권한 실패·요청 검증 및 일반 앱 단위 검사를 실행합니다.
신뢰한 기존 인증서로 후보를 빌드한 뒤 `Tests/Fixtures/run_local_draft_candidate.py`는 해당 후보의 인증서에 고정된 임시 Swift 도우미로 수신·재시도·철회·만료를 확인합니다.
`Tests/Fixtures/run_tts_instruction_approval_ui.py`와 `Tests/Fixtures/run_tts_pronunciation_case.py`는 일회용 합성 설정으로 각각 승인 취소·독립성 및 자막/음성 분리·수동 편집을 확인합니다.
이 테스트들은 설치본·실제 사용자 설정·음성 제공자를 사용하지 않습니다.
