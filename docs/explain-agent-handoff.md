# 해설 탭: 에이전트 지시문과 받은 대본

해설 본문은 외부 에이전트가 만듭니다. 해설 탭의 기본 화면은 **에이전트에 줄 지시문**과 **에이전트가 돌려준 대본**만 다룹니다. 기존 앱 내 해설 생성은 같은 탭의 **고급: 앱 내 해설 생성**으로 옮겼습니다.

## 지시문

- 양식은 **전체 해설**과 **변경분만** 두 가지이고, 각각 편집·초기화할 수 있습니다. 고친 양식만 `settings.json`의 `agentPrompt.full` / `agentPrompt.delta`에 저장됩니다.
- 미리보기, 복사, MCP 조회는 모두 `AgentPrompts.finalText(kind)` 한 함수의 결과를 씁니다. 숨은 접두·접미는 없습니다. 편집한 양식이 곧 최종 문구이고, 비우면 기본 양식입니다. 결과 전달 규칙(`submit_script`)도 기본 양식 본문에 보이는 글로 들어 있습니다.
- **MCP 조회 허용…**은 기존 `get_tts_instructions` 승인 절차(도우미 PID 지정 → 정확한 문구 미리 보기 → 승인, 최대 10분)를 그 양식 하나에 대해 엽니다. `profile` 이름은 그대로 `explain`(전체 해설), `continue`(변경분만)입니다. 승인하지 않은 양식과 `normalize`는 읽히지 않습니다.
- 화면에는 "MCP 조회 허용 중 / 허용 안 함"만 표시합니다. 앱은 에이전트가 실제로 읽었는지, 해설을 쓰는 중인지 알 수 없으므로 '전송됨'·'생성 중' 같은 표시는 없습니다.
- 승인한 문구를 한 바이트라도 고치거나(되돌려도), 초기화하거나, 허용 해제를 누르거나, 앱을 종료하면 소켓이 닫히고 이후 조회는 아무것도 받지 못합니다. 다른 양식의 편집은 영향을 주지 않습니다.
- 앱 내 생성용 `explainPrompt`는 더 이상 MCP로 공유되지 않습니다.

## 받은 대본

- 새 도구 `submit_script`(`scripts/mcp_script_inbox.py`, 소켓 `r.sock`)는 `speak_text`(`mcp_speech.py`, `s.sock`)와 어댑터·소켓·허용 토글이 모두 다릅니다. 앱 메뉴 또는 탭의 **에이전트 대본 받기 (이번 실행)**을 켠 동안에만 받습니다. 기본은 꺼짐입니다.
- 인자: `display_text`(화면 문구, 필수), `speech_text`(낭독 대본, 선택), `idempotency_key`. 텍스트는 각각 UTF-8 12,288바이트 이하입니다.
- 도착한 대본은 수신함에 쌓이기만 합니다. 재생하지 않고, 편집기를 바꾸지 않고, 재생 중인 음성에도 영향을 주지 않습니다.
- 같은 키·같은 내용의 재시도는 `duplicate`로 한 건만 남습니다. 편집기로 옮기거나 지운 뒤의 재시도도 되살리지 않습니다(이번 실행의 최근 128개 키). 같은 키의 다른 내용은 `conflict`, 20건이 차면 `full`입니다.
- **편집기로**는 편집기가 비어 있을 때만 바로 옮깁니다. 다른 내용이 있으면 확인을 받습니다. 직접 붙여넣기(버튼 또는 편집기에 ⌘V)는 MCP 없이도 그대로 쓸 수 있습니다.

Codex 프로젝트 설정 예 (서명 지문 고정은 [빠른 확인 문서](mcp-codex-quick-test.md#실제-연결의-서명-고정)와 동일):

```toml
[mcp_servers.codebasic_tts_script_inbox]
command = "/usr/bin/python3"
args = ["-I", "-B", "/absolute/path/to/SelectedTextTTS/scripts/mcp_script_inbox.py"]
[mcp_servers.codebasic_tts_script_inbox.env]
CODEBASIC_TTS_SIGNER_SHA1 = "TRUSTED_CERT_SHA1_40_HEX"
```

## 화면 문구와 음성 대본

- 편집기는 **화면 문구**(자막: `as_frame`)와 **음성 대본**(합성 입력: '애즈 프레임')을 따로 가집니다. 음성 대본이 비어 있으면 화면 문구를 그대로 읽습니다.
- 음성 대본은 어느 화면 문구에 맞춰 쓰였는지를 기억합니다. 화면 문구가 달라지면 경고가 뜨고, **재생**은 합성 전에 "화면 문구 그대로 읽기 / 이전 음성 대본으로 재생 / 취소"를 묻습니다. 선택 없이는 아무것도 합성하지 않습니다. 음성 대본을 직접 고친 뒤 **지금 문구에 맞음**을 누르면 다시 한 쌍이 됩니다.
- 합성은 사용자가 재생을 눌렀을 때만 시작하고, 편집기에 보이는 문자열을 그대로 넘깁니다. 대본 정규화(LLM)나 붙여넣기 정리를 거치지 않습니다. 문단 분할에서 앞뒤 공백·줄바꿈만 정리됩니다.

## 고급: 앱 내 해설 생성

- 기본 화면은 모델 선택기를 만들지 않으므로, 탭을 여는 것만으로는 모델 목록 조회도 생성도 일어나지 않습니다. 고급 화면을 열면 기존처럼 모델 목록을 확인합니다. 고급 화면은 실행할 때마다 닫힌 상태로 시작합니다.
- 단축키 ⌃⌥⌘E와 Services '코드 해설'은 고급 화면의 **앱 내 생성 시작 허용**(`inAppExplainShortcuts`, 기본 꺼짐)을 켠 경우에만 생성을 시작합니다. 꺼져 있으면 선택한 코드를 고급 화면의 코드 칸에 옮기고 창만 띄웁니다. **기존 사용자에게는 동작 변경입니다.**
- 일반 TTS(⌃⌥⌘R, Services 읽기, TTS 탭), 중지, 자막, 히스토리는 그대로입니다.

## 검증

```sh
./build.sh test                                             # 순수 로직 + 어댑터 + 실제 Swift 수신 소켓
/usr/bin/python3 -I -B Tests/Fixtures/run_agent_script_case.py   # 실제 AppState/AppDelegate/소켓/뷰, 합성·모델은 테스트 대역
```

두 번째 명령은 임시 프로필과 임시 소켓 경로만 사용합니다. 실제 설정·키·지시문·음성 제공자·설치된 앱을 건드리지 않습니다. 화면 배치와 마우스 조작, 실제 에이전트의 모델 턴, 들리는 발음은 확인하지 않습니다.
