# 검토 증거

- 시도 / 자문 회차 / 주 에이전트 / HEAD·기준 SHA: <시도 n/5, 자문 n/3(시도 4~5는 자문 없음), 시도별 재현 차단 지적 수, 재실행 횟수와 사유, 대상>
- 보증 등급: <A·B·C, 승계 여부, 빠진 자리와 이유(미가용·로그인 만료·미승인), C이면 자체 점검 체크리스트와 실행 증거 위치>
- 자문 보고(어드바이저, 결정권 없음): <계열·하네스, 실행 환경(예: CLI 이름·버전)·세션 ID, 요청 모델과 관찰 모델 및 출처 위치, 요청 노력 수준(미지정 포함)과 관찰 노력 수준(확인 불가면 미확인), 보고서 위치·시각, 유효·무효·동일 모델·`incomplete` 구분, 자문 권고>
- 지적: <지적 ID, 심각도, 상황, 영향, 정확한 SHA와 파일·줄 또는 증거 위치, 재현 방법, 직접 실행·정적 추론·미확인, 제기한 어드바이저 수와 다수 여부(⌊N/2⌋+1), 회귀·범위 확장 구분>
- 격리 실행: <실행 ID, 별도 담당, 같은 HEAD·기준 SHA, 환경, 자료 유형과 승인 근거, 명령·절차·결과와 원본>
- 주 모델 결정: <주 에이전트(사용자가 구현을 맡긴 모델)와 실행 위치, 모델과 요청·관찰 노력 수준(확인 불가면 미확인), 결정 대상 HEAD·기준 SHA, 자문 반영 방식, 지적별 처리(수정·후속 이관·기각·중단)와 근거, 다수 의견과 다른 결정의 근거, 재현된 차단 지적의 처리, 다음 단계와 다음 행동 주체·기한>
- 불확실성 아래 결정: <항목·지적 ID, 결정, 남은 불확실성, 결정을 다시 볼 증거 조건, 기록할 이슈, 이후 덧붙인 증거(시각·SHA·출처), 조건 충족 시 주 모델의 수정 필요 판단과 근거, 후속 PR 번호(n/3)와 링크, `review` 병합 뒤 사용자 검토 요청>
- 자동 리뷰: <봇의 검토 SHA와 보조 근거>
- 기여 기록: <에이전트별 계열·하네스(신고·관찰 출처)·요청 모델과 관찰 모델, 역할, 회차와 HEAD·기준 SHA, 작성 커밋 SHA, 이슈 안에서 고유한 지적 ID별 심각도, 주 모델이 정한 처리(채택·보류·기각·미처리)와 해소 여부 및 판단 근거, 이후 회차에서 발견된 누락의 지적 ID와 귀속 근거, HEAD·기준 SHA 안에서 고유한 실행 ID별 결과(통과·실패·미확인). 확인할 수 없는 값은 미확인>
- PR 등록 전 확인: <HEAD·기준 SHA, 등급, 자문·실행·주 모델 결정의 이슈 기록, 주 모델이 정한 PR 등록 준비도(pass·blocked·unverified), 등록 권한 또는 차단 사유와 필요한 근거>. 초안에도 같은 기준을 적용합니다.
- `review` 병합: <증거 충분 조건 항목별 확인, 병합 직전 SHA 재확인, 병합 SHA, 등급, 증거 링크, 병합 주체 또는 병합하지 않은 이유>
- 상의·중단: <상한 도달, 판단 불가, 고칠 수 없는 재현 차단 지적 등 사유, 선택지와 권고안, 다음 행동 주체 사용자>
- 최종 승격 후보 한 개: <최신 HEAD·기준 SHA, 포함된 변경의 등급 요약 또는 후보 없음>. 최종 기본 브랜치 병합은 사용자가 직접 수행합니다.
